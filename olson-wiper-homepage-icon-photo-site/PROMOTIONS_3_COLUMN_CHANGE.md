# Promotions page layout update

The promotions grid uses three product cards per row on wide screens (instead of four), with a 24px gap for improved readability. Existing responsive breakpoints remain: two cards per row from 511px to 790px and one card per row at 510px and below. Product images, item codes, sizes, and prices have not been changed.

Deploy by extracting the root-level files into the existing olson-info-site repository, overwriting the matching files while retaining the .git folder.
