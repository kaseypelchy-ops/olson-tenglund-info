# Footer management credit update

Based on the Olson & Tenglund SEO/AEO/GEO Phase 3 website package.

- Added a discreet footer credit on all twelve HTML pages: **Website managed by Kasey Pelchy of Cwlwm Systems**.
- The credit links to https://cwlwmsystems.com and opens in a new tab.
- Added styling to `site.css` to keep the credit small and separate from store information.
- The approved hero, popup, Facebook integration, guides, sitemap, and schema were preserved.

## Deployment
Copy the contents of this archive over the existing `olson-info-site` directory (do not delete `.git`), then run:

```powershell
git add .
git commit -m "Add Cwlwm Systems footer website credit"
git push origin main
```

No sitemap or Search Console changes are necessary.
